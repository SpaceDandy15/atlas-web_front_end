# Things I Learned

Throughout this project, I gained valuable insights into creating accessible, user-friendly, and functional forms using HTML and CSS. Here's a summary of what I learned:

## HTML Forms
- **Form Structure**: Learned to use `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<textarea>`, and `<button>` for building forms.
- **Input Types**: Chose appropriate input types (`text`, `email`, `search`) to capture data effectively.
- **Form Attributes**: Used `required`, `placeholder`, `max-length`, `autocomplete`, and `accesskey` to enhance form usability.

## Form Validation and Feedback
- **Client-Side Validation**: Applied `pattern`, `required`, and `maxlength` attributes to ensure correct user input.
- **Error Messages**: Provided helpful error messages for users to correct their inputs.

## Accessibility
- **Accessible Elements**: Used `aria-label` to make forms more accessible to screen readers and `accesskey` for keyboard navigation.

## Search Forms
- **Search Functionality**: Built a search form with an input field and submit button, placed inside a navigation bar.

## Styling Forms
- **CSS Styling**: Customized form fields, buttons, and error messages using CSS. Applied styles for valid and invalid inputs using pseudo-classes.

This project helped me understand web form best practices, validation techniques, and how to create accessible, styled forms.
